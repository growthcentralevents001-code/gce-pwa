## Keep product governance ≠ statutory grievance

| Track | Example | Route |
|-------|---------|-------|
| Product / Circle dispute | Category/business dispute inside Connect | CBDP → Platform Relationship Manager (product) |
| Statutory / consumer / privacy | Customer legal complaint; DPDP request | Support → Compliance/Legal — **not** only CBDP |

Do not tell a consumer their only path is a Circle Governing Body.

## Flow

```text
Complainant (customer / member / Venue / BDP / client)
    → Support (ops_cases)
        → responsible vertical (Marketplace / Connect / Enterprise / Finance)
            → Compliance / Legal if statutory, privacy, fraud, media, regulator
                → resolution + audit
```

Existing technical hooks: `ops_cases` types include `refund`, `privacy`, `compliance`, `security`, `general_support` (Phase 13). `/ops/support`, `/ops/privacy`.
