## How to use this register

- Prefer **primary** government / Gazette / regulator sources.
- Professional commentary is recorded only as **secondary** explanation.
- Do **not** paste large copyrighted statutory text.
- Cursor/AI has **not** certified compliance from these sources.
- Where commencement is **phased**, publication date is **not** universal immediate applicability.

**Forbidden:** inventing Acts, Rules, circulars, rates, exemptions, or a fictional “DPIIT Act and Rules 2023”.
